# Carry-forward: what the next authorized live run should answer

Nothing here is authorized. This records what is NOT known, so the next paid run is designed
once rather than discovered mid-flight.

## What is already settled, provider-free

| | |
|---|---|
| history reaches the next planner AND author, CG + literary | demonstrated (fixtures) |
| no stale-note leakage: no-note responses, failed turns, recovery | demonstrated (fixtures) |
| a quote invalidated by a real downstream rewrite is demoted | demonstrated (literary line-editor) |
| settlement through the real adjudication handler, with its refusals | demonstrated (fixtures) |
| beat length follows the moment; navigation, attribution, surface fit | demonstrated, 1 and 4 sentences |

Every scene in every one of those is HAND-WRITTEN. None of it says the model writes well.

## What ONLY a live run can answer

1. **Does the author actually use the permission?** The cap is gone, but a model trained on the
   old rhythm may keep writing one-liners. The failure mode to watch is the opposite one too:
   every beat swelling to four sentences, which is the uniform rhythm Roman warned about.
2. **Does voice arrive without commentary?** "Connected action, perception and character voice
   across the scene, NOT in every beat" is the hardest instruction in the contract to follow. The
   tell is a procession of explanatory observations.
3. **Does the speaker's action land in the adjacent narration beat**, or does it simply vanish
   now that it cannot ride with the line?
4. **Reading TIME per beat.** Still unmeasured by anything static. Pacing on the staged surface
   is a felt property; existing fixtures can be read manually for comfort, but only generated
   scenes show the real distribution of lengths.
5. **Does the history note change what gets written?** The handoff is proven to ARRIVE. Whether
   scene N+1 is better for having it — specifically whether scenes 7-10 stop repeating — is the
   original question and is still open.
6. **Is the OAS register still distinct** from the new CG narration, now that CG may open out?

## Design notes for that run

* Compare against the 2026-10-02 ten-scene issue, which is the baseline Roman read: medians 7-12
  words, 94-100% one-sentence paragraphs in scenes 2-10.
* Measure the DISTRIBUTION of beat lengths, not the mean — the contract asks for variety, and a
  mean of three sentences could be uniformity or could be a healthy mix.
* Keep Scene 1 fixed as the reference; it is hand-authored and unchanged.
* The register change and the memory change landed together, so a single run evaluates both:
  progression, consequential choices, useful memory, richer CG narration, distinct OAS.

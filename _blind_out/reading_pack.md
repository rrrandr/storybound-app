# Blind read — two issues of *The First Sacrifice*

Same seed, same canon, same cast (Lirael / Julian), same author and prose settings, same 20 scenes,
same player inputs. **One variable differs: where each scene's goal came from.** Which is which is sealed.

Scene 1 is generated by the opening-template path in both issues (it does not read the spine), so the
comparison really begins at scene 2.

## How to score

Per scene: **would I click Next? y / n** — and flag it if it feels *repetitive, procedural, inert, or like connective tissue*.
At the end: **which issue would I voluntarily keep reading — A, B, or tie?** Then run `node _blind_pack.js --reveal`.

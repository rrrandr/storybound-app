2. **Stance** (production + offline): 0 first-person occurrences across all canonical_truths,
   unique_predictions and identity_signatures.

6. **Cross-subject substitution**: moving any subject's facet set onto another subject must be
   noticeably wrong. Three subjects must not read as one character described three times.

# PRE-REGISTRATION — serial10b (10 scenes, full stack)

Written BEFORE any output was read. Roman's criteria, recorded verbatim so the
read afterwards cannot drift toward whatever the run happens to produce.

## Interventions active (frozen — nothing else tuned before this run)

- A/50 commercial prose mode (`_armA50`)
- LAW 0 canon authority order (place / cast / population / opening sequence closed)
- Emotional Physics (reactions have causes; reflex vs object categories; late cause allowed)
- Character+ mechanism rotation, 5-scene cooldown, per-character ledger
- Delivery-form cooldown (story-level, closed registry)
- Motif cooldown (surface-level, derived from the scene ring)
- Repair pass: must not reach for a body; use what the scene already supplies

## SUCCESS looks like

1. Fewer unexplained body tells (unlicensed rate below 1.55/1k, and licensing rate above 0%)
2. Fewer repeated surface motifs (no gesture recurring across 3+ scenes)
3. Character+ beats spread across mechanisms (not one letter dominating)
4. A returning mechanism DEEPENS rather than restates
5. Setting remains stable across all 10 scenes
6. No invented cast, no invented lore, no invented attendees
7. Prose still has emotional immediacy

## FAILURE MODES TO WATCH (any one of these is a real result, not a nuisance)

1. **Sterilization** — so afraid of tells that characters read flat. Watch for
   prose that is clean and lifeless: correct, unmemorable, nobody in it.
2. **Mechanism gaming** — same pathology, new vocabulary. heel→ring→hand→breath
   becomes jaw→sleeve→cup→doorway. The ledgers would score this as SUCCESS while
   the reader sees the identical defect.
3. **C+ as checklist** — "every character owns a distinctive behaviour" producing
   exactly the artificiality it was built to prevent.
4. **A/50 tradeoff** — if reduced interiority removes tics AND removes
   psychological depth, that is a product decision, not a bug to fix.

## The decisive artifact

The blind read, not the table. The tables can all pass while the prose fails —
failure mode 2 is specifically the case where every counter reports success.

The question is NOT "does C+ rotate?" (answered: it does). It is:

> After all these interventions, does the system produce a more human-feeling
> serialized character, or did we just replace obvious tics with more
> sophisticated recurring patterns?
